# OFFCHAT

Offline Social Network fürs lokale WLAN. Feed, Chat, Posts — Internet nur für NOX.

## Start

```bash
npm install
npm run dev
```

Die App läuft dann lokal. Aufs Gerät: im Browser „App installieren“ / „Zum Home-Bildschirm“.

Google oder E-Mail zum Anmelden. 10 NOX = 0,99 €. Beim Senden kommen 70 % an.
